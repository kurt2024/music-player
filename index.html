GitHub & Capacitor APK Oluşturma Rehberi

Bu web uygulamasını GitHub'a yükleyip Android (APK) uygulamasına dönüştürmek için aşağıdaki adımları sırasıyla uygulayın.

1

GitHub Deposu (Repository) Oluşturma

  1. GitHub.com'a gidin ve New Repository'ye tıklayın.
  2. Depo adını music-player-app yapın.
  3. Bilgisayarınızda bir klasör açıp bu index.html dosyasını kaydedin.
  4. Terminal / Komut Satırında şu komutları çalıştırın:
git init
git add .
git commit -m "Initial music player commit"
git branch -M main
git remote add origin https://github.com/KullaniciAdiniz/music-player-app.git
git push -u origin main
2

Node.js & Capacitor Kurulumu

Projenizin olduğu klasörde terminal açıp sırasıyla çalıştırın:

# 1. Package.json oluşturun
npm init -y

# 2. Capacitor Core ve CLI yükleyin
npm install @capacitor/core
npm install -D @capacitor/cli @capacitor/android

# 3. Capacitor projesini başlatın
npx cap init "Music Player" "com.soundpulse.musicapp" --web-dir www

# 4. Web klasörü (www) oluşturup index.html'i içine kopyalayın
mkdir www
cp index.html www/
3

Android Platformunu Ekleme & Sync

# Android projesini oluşturun
npx cap add android

# Kod değişikliklerini Android'e aktarın
npx cap sync

# Android Studio ile projeyi açın
npx cap open android

Not: Telefonun hafızasındaki müziklere ve paylaşım özelliklerine erişmek için eklentileri yükleyin:

npm install @capacitor/share @capacitor/filesystem
4

APK Çıktısı (Build) Alma

  1. npx cap open android komutu açılan Android Studio uygulamasında projenizi yükler.
  2. Üst menüden Build > Build Bundle(s) / APK(s) > Build APK(s) seçeneğine tıklayın.
  3. Derleme tamamlandığında çıkan bildiride locate butonuna basarak app-debug.apk dosyanızı alın.
  4. Bu APK dosyasını telefonunuza yükleyip çalıştırabilirsiniz!

Gerekli Konfigürasyon Dosya İçerikleri

capacitor.config.json 
{
  "appId": "com.soundpulse.musicapp",
  "appName": "SoundPulse",
  "webDir": "www",
  "bundledWebRuntime": false
}
package.json (Örnek) 
{
  "name": "soundpulse-app",
  "version": "1.0.0",
  "scripts": {
    "build": "mkdir -p www && cp index.html www/",
    "sync": "npx cap sync"
  }
}
